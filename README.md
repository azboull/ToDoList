# ToDo List

A simple task management application built with Python.

## Features

* Add a task
* Mark a task as completed
* Cancel a completed task
* Delete all tasks
* Automatically save tasks in `todolist.json`

## Installation

Clone the repository:

```bash
git clone https://github.com/azboull/ToDoList.git
cd ToDoList
```

Run the program:

```bash
python main.py
```

## Usage

The program provides several commands:

* `add` → add a new task
* `confirm` → mark a task as completed
* `cancel` → mark a task as not completed
* `delete all` → delete all tasks
* `quit` → save and exit the program

## Troubleshooting

If the program does not work correctly because of corrupted or incompatible saved data, **delete the `todolist.json` file** and restart the program.

The file will be automatically recreated.
